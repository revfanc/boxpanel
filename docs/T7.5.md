# T7.5 实现与评审记录 / PR 描述

对应 TASKS.md：**T7.5 备份与恢复**。只实现本任务及其明确包含的旧面板证书清理，
未实现通知/告警、多服务器、内核升级或其他后续任务；未执行 commit、push、切换分支。
无新增依赖、数据库迁移、前端锁文件、pnpm 冷静期或内核配置格式变更。

## 最终行为

- CLI backup、面板 POST /backup 和每日备份共用 VACUUM INTO 一致性快照与证书归档。
  内含 manifest 的逐文件 SHA-256；排除生成配置、锁、WAL、bak/pending 和备份目录。
  手动导出使用现有 x/crypto 的 scrypt + XChaCha20-Poly1305，口令隐藏交互或从文件读取，
  不出现在日志/进程参数，不持久化。网页仅下载/上传加密文件。
- CLI restore 先验证/迁移候选 DB，核对证书私钥/固定指纹，清空会话并关闭连接，才停止服务与替换目录。
  原目录完整留存，配置通过原 Manager.Restart 的 check/原子替换/存活/防火墙流程生成；
  面板启动后验证本机 HTTPS readiness。失败还原目录、服务及受管规则；回滚失败明确报告人工修复。
- 面板恢复确认后通过 systemd-run 独立任务完成同一恢复流程，参数只有候选目录和运行路径。
  安装脚本 --restore 的全新安装跳过 init，沿用备份账号与密钥；先恢复 DB，再装缺失的原版本内核/单元并生效。
- 生产 UTC 每天首次运行自动备份，保留最近 7 份（0700/0600），原子保存尝试/成功时间及结果。
  设置页展示状态和同机风险、下载/上传、加载/错误及覆盖确认；口令不进入 Query/mutation 缓存。
- 证书成功切换后保留当前与上一份 panel bundle，previous_file 持久化；其他旧 bundle 清理。
  备份快照/证书读取与激活/清理通过 flock 互斥，不清理 Hysteria2、账号或原备用材料。

## 规格缺口的最小补齐

1. 加密外层不是 gzip，扩展名定为 `.tar.gz.enc`，其解密结果才是指定的 tar.gz；
   v1 头/KDF/nonce/AAD 明确定义在 SPEC §15。口令按 Unicode 字符计数，最多 1024 UTF-8 字节。
2. 明确 64 MiB 输入、256 MiB 解压总量、512 数据文件、128 KiB manifest 限制；
   拒绝穿越、绝对/Windows 路径、链接、设备、目录、重复文件/manifest 键、尾随或截断数据。
3. 本任务明确支持一个可迁移的标准 data-dir 布局，拒绝独立外置 DB/证书/配置及数据目录内的内核二进制，
   防止遗漏固定指纹材料；data-dir 可覆盖。此边界在 CLI/API 提供下一步建议，文档同步。
4. 每日定义为 UTC 日历日，启动补当天一次，失败次日再试。自动备份不备份自己或状态，原目录保留不轮转。
5. 只有使用原域名并改 DNS 才能保持原地址可达；IP 迁移仍需 set-host 和修改客户端订阅地址。
   保留身份不能让旧 IP 自动指向新 VPS，README/界面已明确。
6. 自动回滚覆盖普通失败；SIGKILL/断电不宣称跨 DB/目录/systemd 的硬件原子事务。
   保留完整 pre-restore 和失败候选，锁中断排障见 INSTALL §8。

[scrypt](https://pkg.go.dev/golang.org/x/crypto/scrypt)、
